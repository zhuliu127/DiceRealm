四、关键设计决策与勘误
----------------------------------------------------------------
1. 弹层作用域挂法（踩坑记录）
   showModalBottomSheet 的 context 沿 Navigator 祖先链找 InheritedWidget，
   若 RoomScope 挂在 MaterialApp.home 里，弹层**找不到**作用域。
   测试夹具与真实接线都应把 RoomScope 放在 MaterialApp.builder（包住
   Navigator）或更上层。本轮测试 helper _hostApp 用 builder 挂载，
   并有一条专测「弹层内能读到本机只读面」钉死这一点。

2. R2a「需其同意的 5 项」名单（与第一报备有修正，请确认）
   全库只有「疯狂发作中的座位在需其同意的 5 项里被过滤」一句，无名单。
   第二批按 **POLICY confirm 同源 + 权威端拒绝分支对齐** 重新定为：
       madness.cure / sheet.healwound / aid.apply / aid.psycho / state.request
   （前四 confirm:kp，state.request 是 state.edit.other 的等价别名、
     confirm:owner；后两项是弹层里 9 项之外的补充入口）。
   另外把 sheet.sancheck / sheet.sanloss 放进 kKpMadBoutExtraOps：
   domain 的 sheetSanCheck / sheetSanLoss 明确对「疯狂发作中」目标返回
   定向拒绝文案，按 §7 K6「UI 判据与权威端拒绝分支逐条对齐」必须一并过滤。
   → 口径集中在两个文件级常量 kKpConsentOps / kKpMadBoutExtraOps，
     若 QA/PM 手上有确切 R2a 名单，改这两行即可，widget 树零改动。

3. 橡皮「段级删除 + 手势末尾一次提交」
   KpEraser 把 begin/move/finish 三段收口：begin 拷快照、move 调
   view/scene_view.dart 的 eraseStrokeSegments 只做本地演算、finish 是
   唯一 commit 出口（一次 map.strokes.set 全量）。测试注入 eraser 模拟
   3 个手势点：手势期间 f.sent 为空，finish 后恰好 1 条，且笔迹被切成
   2 段。舞台（T03）按同一签名可复用，不必等本文件。

4. 加怪「本地不发包」
   addLocalActor 只写 RoomUiLocal.pendingActors，用 setTool(local.toolMode)
   触发一次局部重建；测试断言 sent 里零 combat.actor / combat.pool.set /
   combat.start / map.mark。候选池随 combat.start 的 actors 载荷送出。

5. 弹层分派表
   sheet_kp_panel.dart 的 openKpSheet(ctx, sheetId) 是 7 个 id 的唯一入口
   （kKpSheetIds）。第一批用回落占位、第二批已换成真实弹层，未引入任何
   跨任务编译阻塞。saveSlots 属 T05，本轮不越界建文件，点它只给只读说明。

6. 三条「他人视图」口径
   sanText(full:true) 内部已按 MemberStats.hasMaxSan 收口，所以直接传
   full:true 也不会出现 'SAN 40 / 60'；madnessText(self:false) 只显
   madnessCount；手绘板笔数优先读本机只读面 boardBySeat[seat]['strokes']，
   玩家裁剪态回退 boardCountOf。测试注入明确置 null 的裁剪态逐条钉死。

7. 双层信封的 op 键（见验收⑤）——不是缺陷，是适配层口径。
