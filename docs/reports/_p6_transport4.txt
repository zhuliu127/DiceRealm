一、补上上一轮遗漏的**关键缺口：建房侧没起服务**
----------------------------------------------------------------
上一轮我只接了「加入」，`_create()` 还在用 `bootLocalRoom` ——
那意味着 **KP 建的房根本不会广播，别人永远搜不到**，
「加入」那条路也就永远走不通。

补法：
  · `room_boot.dart` 新增 `bootHostedRoom(...)`
    —— 与 `bootLocalRoom` 的唯一区别是 session 换成 `HostingLocalSession`
  · `_create()` 改用它；横幅如实报网络状态：
      连上了：「房间 XXX 已创建 · 局域网已开（http://192.168.x.x:4211）· 同伴可搜到」
      没连上：「房间 XXX 已创建 · 未连局域网（只有你自己能进）」
  · `RoomNetFactory.host()` 加 `hub` 参数，让建房时复用同一个 hub
    （否则存档 / 存档槽 / KP 面板会各看一份）

二、修的一个幽灵房缺陷
----------------------------------------------------------------
`RoomBoot.dispose()` 原来只有 `local.dispose()` —— **不碰 session**。

P6 之后 session 是 `HostingLocalSession`，它持有局域网服务。
只清 local 就退出 → **服务还在跑、广播还在发** → 别人一直能搜到一间
已经没人管的房（幽灵房）。

修法：
  · `RoomBoot.dispose()` 改成 `local.dispose() + session.dispose()`
  · 加 `_closed` 幂等守卫（`State.dispose()` 与路由 pop 会各调一次）
  · `RoomBoot` 从 `const` 构造改为普通构造（要存可变字段）

三、旁观者入座
----------------------------------------------------------------
`_freeSeat(role)` 原来对 spectator 直接返回 null（第一版没开放）。
现在支持：玩家找 `p1..p6`，旁观找 `sp1..sp4`。

**两族座位分开找，绝不混用** —— 旁观者是裁剪更狠的视角
（看不到别人手绘板、看不到私有素材），分错族等于给了错权限。

测试覆盖：
  · 旁观者分到 `sp*` 而不是 `p*`
  · 收到 sync（只是裁剪更狠）
  · `state['board']['strokes']` 为空 —— 看不到玩家的手绘笔迹

四、测试隔离：三个开关（这一节的教训比代码值钱）
----------------------------------------------------------------
接完线后全量测试红了 2 条，根因不是业务逻辑，是**测试环境**：

① 多个用例抢 4211 端口
   → `RoomNetFactory.servicePortOverride`（测试置 0，系统分配）

② `testWidgets` 的 FakeAsync **推不动真实的 socket bind**
   于是 `await bootHostedRoom(...)` 永远不返回，页面进不去
   （表现是「找不到大厅页」，看起来像 UI bug，其实是测试模型冲突）
   → `RoomNetFactory.networkEnabled`（测试置 false）
     关掉后 `HostingLocalSession` 仍会构造（`pump` 变 no-op），
     类型与生产一致，UI 逻辑不变

③ 真 UDP 扫描拖慢每个用例 1.2s，且受防火墙影响结果不稳定
   → `RoomNetFactory.discoveryEnabled`（测试置 false）

★ 三个开关都是 `RoomNetFactory` 的静态字段，测试 `setUp` 里关、`tearDown` 里复原。
★ 教训：**UI 测试与真实网络 I/O 是冲突的**。要么把 I/O 抽成可注入端口，
  要么留一个明确的开关。硬跑真 I/O 会得到「看起来像业务 bug 的环境 bug」，
  排查成本极高（这次花了 3 轮才定位到 FakeAsync）。

六、P6 当前完整链路（可对照验收）
----------------------------------------------------------------
  KP 建房
    → bootHostedRoom()
    → RoomHost 装配 + LanRoomHost.start()（HTTP:4211 + UDP 广播:4210）
    → HostingLocalSession（本机视角 + 网络双投递）
    → 每次 host.intent() 的 SendPlan 同时喂本机 client 与 socket

  玩家/旁观加入
    → 输 6 位房号
    → LanDiscoverer.scan() 找这间房（1.2s）
    → LanClient.connect() 握手（hello → joined）
    → 服务端分配座位（p1..p6 / sp1..sp4）+ attachPeer 进花名册
    → 客户端按分配座位重建 RoomClient
    → 服务端补一份 sync（按该座位裁剪）
    → RemoteSession 供 UI 使用（UI 不知道自己跑在网络上）

  退出
    → RoomBoot.dispose() → session.dispose() → server.stop()（连广播）
