【2.1】B 的 bug 详情（唯一一处实质差异）
改前 `room_model_host_core.dart#_onRoundBoundary`：
    if (mental.contains('不定疯狂（症状消失）')) { fadedArm[seat] = false; }
- 用户把状态改名为「潜在疯狂」后，**仍处潜在疯狂的座位永远命中不了这条 if**；
- `fadedArm` 在回合边界被 `clear()` → 键缺失 → `fadedArm[seat] != false` 判为 **true**；
- 结果：**「本回合任意损失即复发」跨回合一直生效**，而老 APP `room-model.js:984-1000`
  的语义是「回合推进时对仍处 FADED 的座位显式置 false（disarm），使复发需重新累计
  ≥ ceil(maxSAN/5)」。
修法：改用状态机判据 `mental_state.isPotentialMadness(mental)`（内部先
`normalizeMentalList` → 新旧两个取值一次覆盖），并写清注释。
副作用：无（正常 / 临时疯狂的座位仍不会被写 false —— B3 用例钉死）。

【3】C · 自动头像 PNG 化

方案（三层，职责不混）：
1. `domain/avatar.dart`（纯 Dart，零引擎）
   - 新增 `AvatarSpec`（bgTop / bgBottom / foreground / initial / rotationDegrees / dots）
     + `specOf(name, flavor)`：**取色与散列只算这一次**，SVG 与 PNG 都读它。
   - `make()` 改为读 `specOf`，输出**逐字节不变**（既有 avatar oracle 全绿）。
   - 新增 `isAutoAvatarSvg()` / `specFromSvg()`：从老卡里那条 SVG dataURI **反解**视觉参数
     —— 这样「本机 SVG」与「远端 PNG」连 `warm` 调色都逐像素同源（用名字重算会丢 flavor）。
2. `ui/widgets/auto_avatar_png.dart`（UI 层，可用 Flutter）
   - `PictureRecorder + Canvas + TextPainter` 照抄 SVG 的 `viewBox="0 0 240 240"`：
     渐变底（左上→右下）/ r=104 α.16 外环 / r=88 α.42 内环 / 上半弧 rotate(rot) /
     `dots` 个 r=2.2 α.55 圆点 / serif 98px w700 首字（盒中心对到 (120,124)）。
   - `toImage` → `toByteData(png)` → base64 → `data:image/png;base64,…`。
   - 体积降级阶梯 128 → 96 → 64 → 48，任一档 ≤ 20000 即返回。
   - 可注入端口 `autoAvatarPngEncoder`（T1：widget 测试换同步替身）。
3. `ui/room/sheets/card_sheet_payload.dart#cardToRoomSheetForReport`（绑卡上报）
   - ① 有上传头像 → 走既有 `avatarThumbEncoder`（64px PNG，原逻辑一字不动）；
   - ② 没有 → `autoAvatarSpecOf(card)`（老卡 SVG 反解 / 无头像按名字现算）→ PNG；
   - ③ 仍拿不到 → **删掉 `avatar` 键**（老 APP「没有头像 → 不占广播体积」）。

体积实测（`test/...C4`，128px）：
  · `data:image/png;base64,` 开头，PNG 魔数 `89 50 4E 47 0D 0A 1A 0A` 校验通过
  · 长度 3xxx 字符量级（用例断言 `>500` 且 `≤20000`；远低于老 APP 的 20000 上限）
  · `roomAvatarDataUri(uri) == uri` → 能被房间广播判据接受（这条正是改前 SVG 挂掉的地方）

老卡兼容：`avatar.make()` 产出的 SVG 仍在卡里、**不被覆盖**（`ensure()` 原样返回，C7 钉死）；
本机显示侧对 SVG 的既有降级（首字圆点）不变、不抛不空白；广播侧一律换成 PNG。

C 的测试（8 条）：同源参数 4 个名字逐一相等 / warm 调色反解 / 判据分得清 PNG vs SVG /
真 PNG 且 ≤20000 / 无头像→PNG（首字同源）/ 老卡 SVG→反解后转 PNG / 老卡不炸 / 生成失败降级删键。

【7】自己踩的坑（照抄给下一位，省时间）
1. **本批最大的坑：一开始以为「广播没接通」**。实际 `diceDirect → diceRoll → emit(dice, public)`

   domain 代码。**教训：先证明症状，再动手。**

4. **`picture.toImage()` / `toByteData()` 在 widget 测试的 fake-async 区域里永不完成**。
