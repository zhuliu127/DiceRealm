# 图标重制报告（程序绘制替代 AI 生图）

## 问题
`ui_assets/icons/{general,dice}` 原先是「AI 生图 → 抠背景」的产物，三个硬伤：
1. **边缘脏**：抠图残留白色/黄色像素，放大后是锯齿 + 光晕；
2. **风格不统一**：线宽、构图、透视每次生成都不一样，20 个图标像从三家店买的；
3. **尺寸不一**：各图 200~210px 不等，铺在列表里高低不齐。

## 方案：用代码画，不用生成模型
新建 `tool_img/draw_icons.py`，几何绘制 + **4 倍超采样降采样**：
- 边缘由 LANCZOS 抗锯齿产生，**没有任何抠图残留**；
- 线宽统一（`LW = 15` 常量，在 256 坐标系里）；
- 全部 256×256，四边留 20px 安全区；
- 画成**纯白 + alpha**，Flutter 侧用 `ColorFilter`（`srcIn`）染成任意主题色 —— 一套图适配两套皮肤，不用出两版。

### 校验结果（脚本自动断言）
20 个图标：尺寸全部 256×256、**四角 alpha 全为 0**、半透明过渡像素占比 **< 6%**。无异常。

## 用法（接入时）
```dart
ColorFiltered(
  colorFilter: ColorFilter.mode(Palette.goldStr, BlendMode.srcIn),
  child: Image.asset('assets/images/icons/dice/d20.png', width: 20, height: 20),
)
```
白色线稿 + `srcIn` = 任意主题色，且**不需要为亮色皮肤另出一套图**。
