## 出图时统一注意（沿用既有规范）

- 深色版：`#241A44 → #120E22` 底、金线 `#D9B45A / #F0C96A`、星云 + 星点
- 亮色版：`#FBF7EE → #E8DECB` 底、金线 `#B8873A / #D9B45A`、极淡紫雾
- 装饰图一律**不要烧字**（标题由 App 渲染，字体和主题色才跟得上）
- 图标类：透明背景，**别在 prompt 里写 `transparent`**（该模型会吐黄黑噪点），写 `completely flat uniform pure black background (#000000)` 再抠
- 复杂小图标**不要用 2048×2048**（会降质出噪点），1024 或雪碧图更稳
